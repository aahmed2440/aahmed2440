# Security Policy

This repository primarily supports the public GitHub profile for Azad Ahmed and is not intended to host production services or sensitive operational systems.

## Public-Release Rules

Do not publish or commit:

- passwords, API keys, access tokens, private keys, certificates, recovery codes, or secrets;
- confidential employer, client, partner, or third-party information;
- internal network diagrams, non-public IP addresses, credentials, or restricted infrastructure details;
- personally identifiable information or private records;
- unreviewed production configuration or sensitive operational data.

## Responsible Disclosure

If you believe public material in this repository exposes sensitive information, please avoid reposting the material publicly. Use an appropriate private contact channel associated with this GitHub profile.

## Engineering Posture

Public artifacts should favor minimum necessary disclosure, explicit maturity labeling, provenance where relevant, and progressive validation before scale.
