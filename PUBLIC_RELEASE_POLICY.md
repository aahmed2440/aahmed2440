# Public Profile Disclosure-Control Policy

This repository is intentionally public. Therefore every tracked file, filename, commit message, branch name, issue, pull request, screenshot, document, and historical revision must be treated as externally visible.

## Allowed public content
- General professional capabilities and engineering principles
- Publicly approved, generalized, synthetic, or independently reproducible technical material
- Content whose disclosure has been intentionally approved

## Do not publish
- unreleased mission, project, workstream, architecture, maturity, roadmap, deadline, partner, employer/client, or integration names;
- secrets, credentials, tokens, keys, certificates, session data, or private configuration;
- internal endpoints, account IDs, non-public infrastructure, production topology, or operational logs;
- confidential employer/client/vendor/partner material;
- unpublished invention details, patent drafts, or restricted research records;
- personal/private/regulated data;
- screenshots or documents containing hidden metadata, IDs, URLs, comments, or restricted context.

## Release classification
- **R0 Restricted Mission** — never public.
- **R1 Internal Engineering** — private by default.
- **R2 Reviewable External** — generalized material requiring disclosure review.
- **R3 Approved Public** — intentionally public and reviewed.

## Historical visibility
Changing the current README does not remove earlier public Git history. History remediation must be deliberate and evidence-preserving.

## Authority
Automated checks assist publication safety but do not authorize publication. Final release authority remains human-only.
